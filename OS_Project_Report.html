1. ABSTRACT

In multiprogramming operating systems, the CPU scheduler is responsible for selecting active processes from the ready queue and dispatching CPU time slices to optimize system performance metrics such as CPU utilization, throughput, waiting time, and turnaround time.

This project implements a comprehensive CPU Process Scheduling Simulator in C++ (C++17) covering four classical CPU scheduling algorithms:

  1. First-Come, First-Served (FCFS): Non-preemptive, arrival-time ordered policy.
  2. Shortest Job First (SJF): Non-preemptive, burst-time optimal policy.
  3. Priority Scheduling: Non-preemptive, priority-driven policy (lower integer value = higher priority).
  4. Round Robin (RR): Preemptive, cyclic time-sliced policy with customizable time quantum.

The simulator computes exact Completion Time (CT), Turnaround Time (TAT), and Waiting Time (WT), constructs dynamic ASCII Gantt Charts illustrating processor execution blocks and idle intervals, and provides an automated Comparative Benchmark Engine that analyzes the algorithms side-by-side to determine the optimal policy for any input dataset.

2. MATHEMATICAL FORMULAS

For a set of $N$ processes, where process $P_i$ has Arrival Time $AT_i$, Burst Time $BT_i$, and Completion Time $CT_i$:

Metric Formula Physical Meaning
Turnaround Time (TAT) TAT = CT - AT Total time elapsed from process arrival to final completion.
Waiting Time (WT) WT = TAT - BT Total time spent waiting in the ready queue.
Average Turnaround Time Avg_TAT = (Σ TAT) / N Overall system efficiency metric.
Average Waiting Time Avg_WT = (Σ WT) / N Average delay experienced by waiting jobs.

3. ALGORITHM COMPARISON & CHARACTERISTICS

Algorithm Type Selection Criteria Key Advantages Key Disadvantages
FCFS Non-preemptive Arrival Time (FIFO) Simple, zero overhead, fair order Convoy Effect; high average waiting time
SJF Non-preemptive Shortest Burst Time Minimizes average waiting time Starvation of long jobs; impossible to know exact future burst
Priority Non-preemptive Priority Value Accommodates critical tasks Indefinite blocking (starvation) of low-priority jobs
Round Robin Preemptive Time Quantum (Q) Excellent responsiveness; no starvation Context switch overhead; higher average waiting time if Q is small

5. CRITICAL OBSERVATIONS & SYSTEM TRADE-OFFS

  1. Optimality of SJF: SJF produced the minimum average waiting time of $6.60 ext{ ms}$, confirming the theoretical theorem that scheduling short jobs first minimizes ready queue queuing delays.
  2. Convoy Effect in FCFS: In FCFS, short processes P2 (burst 3) and P5 (burst 4) experienced prolonged waiting times because process P3 (burst 8) held the CPU uninterrupted, resulting in an average waiting time of $8.20 ext{ ms}$.
  3. Impact of Time Quantum in Round Robin: With $Q=2 ext{ ms}$, Round Robin preempted jobs frequently, producing 14 context switches. While responsiveness was optimal, average waiting time increased to $12.60 ext{ ms}$.
